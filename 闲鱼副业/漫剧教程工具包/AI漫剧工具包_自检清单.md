# AI漫剧制作工具包 - 发布前自检清单

> 每集发布前逐项检查，全部打✓再发布。打印出来贴在电脑旁边！

---

## 一、角色一致性检查 ✅❌

- [ ] 同一角色在所有画面中外貌一致（发型、发色、服装）
- [ ] 同一角色的体型比例没有突变
- [ ] 角色面部特征可辨认（不是换了个人）
- [ ] 服装更换有剧情理由（不是莫名其妙换了）

**快速检验法**：把所有画面缩略图排成一行，一眼扫过去角色是否像同一个人

---

## 二、字幕同步检查 ✅❌

- [ ] 每句字幕出现时间=对应配音开始时间
- [ ] 字幕消失时间=配音结束时间+0.2秒
- [ ] 没有字幕比配音提前或滞后超过0.3秒
- [ ] 字幕不遮挡角色关键面部/动作
- [ ] 没有错别字、漏字

**快速检验法**：静音看一遍字幕，再关字幕听一遍，分别确认

---

## 三、画面连续性检查 ✅❌

- [ ] 同一场景中背景没有突变（白天↔黑夜、晴天↔雨天）
- [ ] 角色站位方向没有跳切（A在左边突然变右边）
- [ ] 道具位置合理（手里的东西不会消失又出现）
- [ ] 受伤/变化有延续性（上一集受伤下一集还有痕迹）

**快速检验法**：重点看相邻两帧画面的衔接处

---

## 四、节奏紧凑性检查 ✅❌

- [ ] 每帧画面停留1.5-2秒（不超过3秒除非特殊效果）
- [ ] 没有连续3帧以上无新信息的画面
- [ ] 对白没有超过10秒没有画面变化
- [ ] 90秒的集包含至少2个情绪转折点
- [ ] 开头3秒有冲击力（不是缓慢展开）

**快速检验法**：2倍速播放，如果觉得无聊的地方=节奏有问题

---

## 五、音画配合检查 ✅❌

- [ ] 配音音量清晰，不被BGM盖住
- [ ] BGM风格匹配剧情情绪（战斗→紧张BGM，温情→柔和BGM）
- [ ] 音效（开门、脚步、爆炸）时间点对齐画面
- [ ] BGM在关键对白处自动压低
- [ ] 转场音效不突兀

**快速检验法**：闭眼只听音频，情绪线是否完整流畅

---

## 六、内容合规检查 ✅❌

- [ ] 没有裸露/色情画面
- [ ] 暴力场景不过度血腥（AI生成的容易翻车）
- [ ] 没有现实品牌logo/商标
- [ ] 没有敏感政治/宗教内容
- [ ] AI生成的人物没有手指异常（6指/扭曲）——有的话截掉或重画

---

## 七、平台适配检查 ✅❌

| 检查项 | 抖音 | 小红书 | B站 |
|-------|------|--------|------|
| 画面比例 | 9:16竖屏 | 9:16竖屏 | 16:9横屏 |
| 时长 | 60-120秒 | 30-90秒 | 3-10分钟 |
| 封面 | 前1秒截帧 | 单独做封面 | 单独做封面 |
| 标题字数 | ≤30字 | ≤20字 | ≤80字 |
| 标签 | 3-5个 | 5-8个 | 3-5个 |

---

## 常见坑速查表

| 坑 | 症状 | 急救方案 |
|----|------|---------|
| 角色脸变了 | 观众弹幕"这是谁？" | 锁定seed值+提示词模板一字不改 |
| 字幕乱跑 | 声音和字对不上 | 用SRT格式手动调时间轴 |
| 节奏拖沓 | 完播率低于40% | 删掉所有无台词无转折的过场 |
| 6指/扭曲手 | 评论区嘲笑 | 手部特写用截取手法避开，或后期P掉 |
| BGM太吵 | 听不清台词 | BGM压到配音30%，高潮压到20% |
| 开头无聊 | 3秒跳出率>70% | 第一帧必须是冲突/悬念/视觉冲击 |
