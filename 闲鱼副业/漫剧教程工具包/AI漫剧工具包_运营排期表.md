## 三、标题公式

### 万能公式
**数字 + 痛点/悬念 + 情绪词**

### 实例模板
| 题材 | 标题模板 | 示例 |
|------|---------|------|
| 教程类 | N步学会XX｜零基础也能XX | 6步学会AI漫剧｜零基础也能月产30集 |
| 炫技类 | 用AI做了XX｜结果XX了 | 用AI做了部末世漫剧｜播放量破10万了 |
| 对比类 | XX前 vs XX后｜差距XX | 学AI漫剧前后｜收入差了5倍 |
| 悬念类 | 这个XX居然是AI做的｜看完我XX | 这个末世短片居然是AI做的｜看完我沉默了 |
| 数字类 | XX天从0到XX｜全过程公开 | 30天从0到10万粉｜AI漫剧全过程公开 |

## 五、互动SOP

### 前1小时（决定推荐权重）
| 时间 | 动作 |
|------|------|
| 发布后0-5分钟 | 自己先评论1条（引导讨论） |
| 发布后5-30分钟 | 每条评论必回，越快越好 |
| 发布后30-60分钟 | 回复所有新评论+点赞所有评论 |

### 日常维护
| 动作 | 频率 | 说明 |
|------|------|------|
| 回复评论 | 24小时内 | 超时不回=放弃互动权重 |
| 评论区置顶 | 每条内容1条 | 引导关注/下集预告 |
| 删除负面评论 | 随时 | 恶意/引战直接删 |
| 私信回复 | 24小时内 | 潜在客户/合作机会 |

### 引导评论话术
```
"你们觉得XX会怎么选？评论区告诉我👇"
"下一集XX会死吗？猜对的我回关"
"想看我出XX教程的扣1"
```

## 七、数据复盘清单（每周日做）

| 指标 | 达标线 | 不达标对策 |
|------|--------|-----------|
| 完播率 | ≥50% | 节奏太慢→删冗余画面 |
| 点赞率 | ≥3% | 内容不戳→换标题/开头3秒 |
| 评论率 | ≥0.5% | 无互动点→加引导话术 |
| 转发率 | ≥0.3% | 无分享欲→加共鸣点 |
| 涨粉率 | ≥1% | 人设不清→加强个人IP |

> 核心逻辑：完播率>点赞率>评论率>转发率，优先解决完播率问题
