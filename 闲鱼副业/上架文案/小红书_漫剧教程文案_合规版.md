# 小红书合规版文案 - AI漫剧制作教程（去掉所有赚钱暗示）

## 📌 正文文案

🎨 AI漫剧制作全流程｜6步从零学会，超有成就感的创作体验！

一直想自己做个小动画，终于研究通了！分享我的完整制作流程👇

**Step1 选题+剧本** 📝
→ 热门题材：末世/甜宠/穿越/悬疑
→ 剧本结构：每集90秒=3个转折点
→ 工具：ChatGPT/豆包写分集大纲
→ 💡关键：前3集必须有第一次冲突，观众不会等！

**Step2 AI生成画面** 🎨
→ 工具：即梦/豆包/Midjourney
→ 提示词模板：角色描述+场景+构图+光线+风格
→ 💡关键：用同一套提示词模板+种子值，保证角色脸一致

**Step3 配音+字幕** 🎙️
→ AI配音：豆包TTS/剪映AI配音
→ 音色选择：旁白沉稳声+角色匹配声
→ 字幕：SRT导入→调时间轴→统一字体
→ 💡关键：每句话间隔留0.3秒，听着才有呼吸感

**Step4 剪辑合成** ✂️
→ 剪映专业版就够了
→ 画面停留1.5-2秒/帧，转场只留淡入淡出
→ BGM音量压到配音的30%
→ 💡关键：0-3秒必须抓住眼球，开头冲击力决定完播率

**Step5 检查避坑** ⚠️
→ 角色脸不一致→锁定提示词种子值
→ 字幕不同步→逐句校对时间轴
→ 节奏拖沓→删掉所有无信息量画面
→ 💡关键：发布前自检4项：角色一致✓ 字幕对齐✓ 节奏紧凑✓ 无穿帮✓

**Step6 发布运营** 🚀
→ 抖音竖屏为主，小红书图文+视频双发
→ 标题要有记忆点，别太普通
→ 前1小时互动量决定推荐权重
→ 💡关键：坚持更新，断更必掉粉！
